# 今日小評

每一天可以有一則短評，檔名就是日期，時區為台北：

```text
data/commentary/2026-10-28.md
```

網站產生時會讀「當天」這份檔案。有寫內容，才會出現在那一天的日報；檔案是空的，或整份都包在 `<!-- 註解 -->` 裡，頁面上就不會有小評區塊。

## 怎麼寫

1. 複製下面的範本，存成 `data/commentary/YYYY-MM-DD.md`（已存在的檔案不要整份覆蓋，直接改內容）。
2. 刪掉 HTML 註解，用一般文字寫。段落之間空一行。
3. 建議 100 到 300 字。不要貼媒體全文，不要寫客戶姓名、電話或其他個資。
4. 推上 `main` 分支。推上去之後，這段文字是公開的。

```markdown
<!--
【今日小評】寫完請刪掉這段註解。
-->

今天想跟客戶說的話寫在這裡。

下一段中間空一行。
```

自動排程每天約台北時間 07:00 會新建一份「只有註解、不會顯示」的當日檔案（若還沒有）。你之後補上文字再推上 `main`，網站會只重畫頁面、不重抓新聞。

也可以到 GitHub 的 Actions 頁面手動執行「每日新聞」。選排程或手動執行時會重抓新聞；只有推送小評或關於我時，才只重畫頁面。
